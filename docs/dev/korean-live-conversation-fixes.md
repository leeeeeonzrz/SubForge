# 韩语直播口语保护与重复复核

日期：2026-10-18。基线：`6524e4f`。本轮为本地源码修复，不训练模型。

## 行为变化

- 翻译校验和离线评估的文本比较保留 Unicode 字母、数字，并统一组合式韩文。
  原先过滤掉韩文的比较结果不能用于判断两条韩语源文是否相同。
  评估报告新增 `metrics_revision`，不同版本须重新评估后才能比较。
- 韩语连续短音节的大量循环只产生音频复核候选。普通短答、强调、拟声和笑声
  不按语气词黑名单删除；无音频的原文润色也不能以“重复字”为由删除韩文。
- WhisperX 的词时间轴允许使用原音局部重识别。原有真实缺口优先，重复复核
  使用剩余预算：合计最多三个目标窗口、180 秒解码音频。替换须满足不同上下文
  解码的一致性、两侧词锚点、保留非循环原文、独立词对齐和语音活动证据。
  证据不足、模型失败或预算不足时保留原字幕，并标记时间段供复核。
- 韩语翻译提示补充省略、短回答、自我纠正、否定、强调及昵称的上下文处理。
  针对译文中残留的成段韩语增加重试信号；孤立人名、歌名不据此删除。
  对话和单人翻译缓存版本均更新。未更换模型、服务商或翻译配置。
- 单纯的重复嫌疑不再被当成缺口而中止后续翻译；真实覆盖缺口和检测失败仍走
  原来的恢复文件及失败路径。正常导出、原文保护和警告都有回归覆盖。

## 本机原音与历史字幕

用户 Downloads 中的直播约 58.5 分钟，现存字幕各 658 条；本轮不改写这些文件。
历史字幕在 05:18.804–05:21.625 和 05:44.866–05:47.963 有两处长音节循环。
候选定位到这两处，所有原文和时间轴保持不变。较晚的同名字幕已有两处局部
改写，不能作为人工正确答案，也不能将两份旧字幕的差异计为本次收益。

使用已有 large-v3-turbo、韩语对齐模型和工作区冻结运行环境，对同一原音的
45 秒上下文和 15 秒正常拟声对照进行基线/候选验证。该验证会临时注入对应
源码，结束时校验并恢复工作区程序文件；不改动已安装应用或用户设置。
短片段识别没有重现历史长循环，因此这组结果只能验证运行与正常内容保留，
不能证明整场直播的漏译率下降或历史循环已自动修复。
最终候选与基线分别输出相同的 21 个、7 个词段，文字和时间轴完全一致。
历史错误字幕的四条源文另做句级状态回放：两处长循环均被标记，四条原文和
时间轴全部保留。历史 SRT 没有真实词级对齐，因而没有伪造对齐来演示自动修复。

另发现历史第 115、117 条产品名称曾出现空译；较晚译文为拉丁字母名称。
现有“必须含目标文字”和名称归属校验可能拒绝这类结果，但缺少当时日志，
不能确认它就是历史失败原因。本轮未添加产品白名单、数字相同即放行规则，
也没有把模型生成术语当作人工确认的事实。
